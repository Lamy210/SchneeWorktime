## Release criteria
1. P0自動テスト全件成功。失敗時に原因が追跡可能。
2. macOS通知・起床・複数モニター・VoiceOverは実機でQA。
3. データ破損時の上書き喪失ゼロを強制障害テストで確認。
4. 法定時間外労働・給与確定を示唆する文言を出さない。
5. 実機CPU/メモリは計測してから性能予算を決める（未計測）。
