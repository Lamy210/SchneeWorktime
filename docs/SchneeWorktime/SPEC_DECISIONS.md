# SchneeWorktime 仕様決定 v0.3

| ID | 決定 | 理由 |
|---|---|---|
| D-01 | 新規macOSアプリ、templateベース | 独立した権限/配布/保守 |
| D-02 | 日次の実働目標420分 | ユーザー指定、正式な法定労働時間の判定ではない |
| D-03 | 標準休憩60分は予測用。記録まで実績扱いしない | 実績を捏造しない |
| D-04 | 初期基準定時18:00、任意設定 | 参考時刻であり残業判定ではない |
| D-05 | 最短達成時刻と休憩込み退勤見込みを別計算 | 実績達成通知の遅延を防ぐ |
| D-06 | 手動打刻、推測打刻なし | スリープ/離席から勤務可否を断定できない |
| D-07 | 退勤後の時間は固定 | 履歴が閲覧時刻で変わらない |
| D-08 | 1つのアクティブ勤務日。日跨ぎは分割なし | 二重計上防止 |
| D-09 | active breakで終了時刻不明なら時刻予測は未確定 | 虚偽の精度を回避 |
| D-10 | 設定は勤務日開始時点でsnapshot。active適用は明示確認 | 途中変更で履歴を変えない |
| D-11 | 保存確定後に通知reconcile | 書き込み失敗時に通知だけ変えない |
| D-12 | 通知はbest effort。厳密に1回だけ/時刻ぴったりは非保証 | OS通知制約 |
| D-13 | 履歴訂正はbefore/after/revisionを記録 | 追跡可能性 |
| D-14 | デスクトップ/メニューバー表示、前面固定opt-in | 業務の邪魔をしない |
| D-15 | ローカル完結・テレメトリなし | プライバシー |
| D-16 | 清算期間の正式残業・給与はMVP対象外 | 会社制度未確認 |
| D-17 | 休憩中退勤は明示確認後、休憩終了時刻を確定 | 開いている区間を残さない |
| D-18 | スリープ等の要確認区間は確定達成と分離 | 実働の推測を確定としない |
| D-19 | 事前予約通知は見込み、確定は記録検証後 | 目標達成の誤認防止 |
| D-20 | 退勤済みなら不足/達成を固定表示する | 履歴閲覧の安定性 |
| D-21 | 通知ID・発火Instant・本文revisionで照合 | 古い時刻の予定を残さない |
| D-22 | 通知本文に勤務時刻・会社情報を既定で含めない | ロック画面での情報漏えいを抑制 |

## UI語彙
- 実績: 記録された勤務・休憩区間から計算した値
- 最短目標達成: 以降中断・休憩なしなら実働7時間に達する時刻
- 退勤見込み: 未取得の予定休憩を含めた予測
- 基準終業時刻: 任意の参考時刻、労働時間の法的しきい値ではない
- 日次目標超過: 420分超過。法定/会社の正式残業を意味しない
- 要確認: スリープ中など実際に働いたか推測できない期間を含む記録

## 留保
- 会社の清算期間、コアタイム、申請が必要な残業・労働時間記録との同期、休憩の時間帯
- 最終的な署名/公証/配布手段、OS別互換性、パネル性能の実測
