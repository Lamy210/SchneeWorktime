# SchneeWorktime — Release Scope v0.6（提案）

機能探索ドキュメントは「採用前」の一覧。MVPの受入条件に追加した項目以外を自動的に確定要件へ変換しない。

## Phase M0: 正しく動作する最小デスクトップアプリ
- Workday時刻管理、実働/休憩/非勤務ギャップ、予測/確定/要確認
- 予定休憩と実績の分離、実働7時間・参考18:00
- メニューバー打刻、遡り始業時刻入力、コンパクト/詳細Glass
- 退勤予定シミュレーション（保存するまで非破壊）。未来休憩が残り時間に収まるか判定し、実現不能/不明を明示
- 既定通知は休憩込み退勤見込みの15分前。任意で30/5分のリードを追加可能。最短7時間の事前通知は別の任意カテゴリ
- 訂正/永続化/再起動復旧/通知再調整/履歴エクスポート

## Phase M1: 振り返りと定型化
- 今日の実績カードと見やすい勤務履歴
- 日/週サマリー（任意の目標であり正式フレックス清算とは別）
- 始業時間/休憩設定のユーザープリセット
- リマインダーの一時ミュート・スヌーズ
- 予定休憩の時間帯設定

## Phase M2: OS連携の追加（権限・省電力PoC後）
- macOS Shortcuts向けApp Intents
- WidgetKit MacデスクトップWidget
- Control Center/メニューバーControls
- オプトインのカレンダー参考表示（EventKit permissions + privacy review）
- 必要ならCSV取り込み/週次計画シミュレーター

## 非採用/独立提案
- 自動勤怠確定（GPS,在席/画面監視）、会社の正本との無断同期
- 法定残業/給与/清算期間の推定判定、未確認の就業規則の自動適用
- 初期MVPのクラウドアカウントや外部サービス必須化

## 採用ゲート
1. 利用者の「今日いつ帰れるか」のユースケースを最短の操作で回答。
2. 実績と試算を混合せず、保存は明示操作に限る。
3. OSスリープ/権限拒否/再起動/通知重複で誤った「残業確定」を表示しない。
4. macOS実機でCPU/RAM/電池消費・通知・画面復旧を検証。
5. OpenSpec CLI strict validation + 対象アプリのSwift/Xcode CIが実際に成功していること。
