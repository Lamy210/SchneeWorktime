# 個人向け勤務履歴サマリー（Phase M1）

本機能はM0配布の必須条件には追加しない。会社の正式な勤怠集計、清算期間、法定残業、給与計算とは独立した閲覧専用の振り返りとする。

- Gregorian暦・明示timezoneの暦日、月曜始まりの週、暦月を選択。半開区間[start,end)を使用し、DSTを固定24時間/7*24時間で近似しない。
- 退勤済みWorkday UUIDを対象とし、最初の実績始業Instantが範囲内にある場合に勤務日全体を集計。深夜跨ぎも分割せず、表示timezone変更で所属期間は再計算され得る。記録時の参考時刻/timezoneは変更しない。
- 実働の上下限、実績休憩、日次目標合計、日次不足・日次超過それぞれの合計、未確認勤務日数を表示する。実働下限と上限が一致しない勤務日を未確認として数える。日を跨いで不足と超過を相殺しない。勤務中/休憩中は除外し、退勤後に反映する。
- 保存されたcatalogのversion・読込時刻に結び付ける。元のjournal、通知、勤怠記録を変更しない。集計加算のoverflowは拒否する。
- 今回はapplication計算とテストのみ。UI・期間移動・CSV・実機検証は後続。M0の配布条件、OpenSpecの既存P0を変更しない。
