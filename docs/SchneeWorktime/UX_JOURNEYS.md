# SchneeWorktime — UX Journeys v0.6（検討案）

実装前のプロダクト体験設計。画面遷移・表示語彙・失敗時の挙動をOpenSpecのcapabilityに結びつける。

## 1. 朝、出社した
1. メニューバーの「出社」を押す。デフォルトは現在時刻だが、時刻選択で11:30などの過去時刻を指定できる。
2. その勤務日の目標420分、休憩予定60分、参考終業18:00を確認。
3. Glassに`退勤見込み 19:30（休憩予定60分を含む）`と`最短7時間 18:30`が表示される。
4. 次回起動時にも同じWorkday UUIDと履歴が残る。

## 2. お昼を取る
1. メニューバー/Glassで「休憩開始」を選択。実働カウンターは止まる。
2. 休憩終了が未定の間は目標時刻を「未確定」とする。
3. 「休憩終了」を押すと実績が記録され、退勤見込みと未来通知を再計算する。
4. 休憩予定の15分追加は、実績の休憩とは別の仮変更。後に実際の休憩を記録した分だけ予測残量を減らす。

## 3. 18:10、あと何分？
前提：11:30出社、12:00〜13:00休憩済み、現時刻18:10。

```text
SchneeWorktime  ·  勤務中
退勤見込み       19:30
残り実働         1時間20分
今日の実働       5時間40分 / 7時間
取得済み休憩     60分
最短7時間達成    19:30
参考18:00        10分経過
[休憩]  [退勤]  [予定を試算]
```

「もし19:00に帰ったら？」→見込み実働6時間30分、**30分不足**。
「もし20:00に帰ったら？」→見込み実働7時間30分、**目標超過30分**。
どちらも試算。**実績や退勤予定は保存ボタンを押すまで変更しない**。
仮に未来休憩が予定されている場合は、その見込み時間も試算に反映し、根拠を表示する。

## 4. スリープ復帰後
- 16:30〜17:30が未確認なら「休憩だった」「勤務は続いていた」「勤務でも休憩でもなかった」を選ぶ。
- 保存前に実働下限/上限・退勤見込み・休憩実績への影響をプレビューする。
- 選択せず閉じた場合は「要確認」を保持し、確定達成として通知しない。

## 5. 退勤
- 「退勤」を押すと今の実働と日次目標の差分を確認し、保存する。
- 目標未達で終了しても、法令違反や給与控除とは表現しない。
- 退勤後は固定値の結果画面に切り替え、カウントダウンが進み続けない。
- 間違った場合は訂正/明示再開可能。履歴は監査revisionと同時保存。

## 6. 表示モード（UX案）
- メニューバー：アイコン＋表示内容を選択（残り時間/退勤見込み/状態）。クリックで出社・休憩・退勤。
- コンパクトGlass：退勤見込み/残り実働/状態を優先。ドラッグ移動、透過、非表示、前面固定opt-in。
- 詳細Glass：実績バー・休憩・参考定時・予定試算・履歴訂正への導線。
- 設定画面：日次目標/休憩/参考時刻/通知/プライバシー/表示位置。

## 初回起動と権限
- 初回起動で通知許可を自動要求しない。利用者が通知を有効にするとき、用途と不達の可能性を説明してから要求する。
- 通知拒否でも勤務計算・保存・退勤見込みは動く。
- メニューバー項目だけを唯一の操作・終了解除導線にしない。macOSのMenuBarExtra onlyアプリで項目を外すとアプリが終了する仕様を考慮し、Glass/設定等の復元導線を検証する。

## 非機能のUX合格条件（提案）
- 出社/休憩/終了はメニューバーから原則2操作以内を目標（測定前の仮目標）。
- 主要状態で「記録」「見込み」「要確認」を文字ラベルで区別する。色だけに依存しない。
- 時計を秒刻みで描画し続ける必要はない。compactは分単位を基本とし、低消費電力を優先。
- UIの見た目が閉じても、勤務記録の保存・通知予定の整合性が崩れない。

## 7. 予定が実現できないときの説明
- 11:30出社、休憩をまだ取らず18:10になった。今の実働は6時間40分。
- 「19:00に退勤」を入力し、今後の休憩予定60分を維持する。
- アプリは「退勤まで残り50分に、予定休憩60分を収められません」と表示する。見込み実働6時間30分などの誤った確定的試算は出さない。
- 利用者が休憩予定を明示的に30分へ変更すれば、19:00時点の見込み実働7時間に更新。ただし休憩実績は0分なので、休憩記録/適用ルールの確認を独立して表示。
- 「今帰る」は例外として、将来の休憩予定を控除せず現在までの記録上の実働を表示する。

## 8. 通知の種類を選ぶ
- 基本通知は、Glassの主表示である「休憩込み退勤見込み」の15分前。例えば19:30退勤見込みなら19:15。
- 休憩を取らない場合の最短7時間到達が18:30でも、18:15には自動通知しない。ユーザーが「最短達成の通知」を有効にするときのみ予約。
- 参考終業18:00は独立通知であり、正式な残業認定の通知にはしない。
- 退勤を記録したら未来の通知は取消対象。ただしOSで既配信の通知は回収できない。
